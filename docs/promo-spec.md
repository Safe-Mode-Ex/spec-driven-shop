# Промокоды в корзине — feature spec

> Итоговая версия мини-спецификации после реализации: журнал решений заполнен. Функция разбита на три шага — каждый со своим scope и критериями приёмки. В реальном проекте это может быть три отдельных файла или один, как здесь.

## Общий scope задачи

Ввод промокода в корзине, применение скидки к итоговой сумме, сохранение между сессиями.

## Out-of-scope

- Серверная валидация промокодов. Список валидных кодов хранится в клиенте.
- Истечение срока действия промокодов.
- Несколько промокодов одновременно. Применяется только один.
- Разные типы скидок (абсолютная, бесплатная доставка). Только процент.
- Регистрозависимость. `SALE15` и `sale15` — один код.

## Constraints

- Не менять структуру данных товаров в корзине.
- Не ломать существующий расчёт итога (текущие тесты должны продолжать проходить).
- localStorage-ключ: `appliedPromo`, значение — JSON `{ code, discount }`.

---

## Шаг 1. Ввод и валидация

### Scope

UI для ввода промокода: инпут, кнопка «Применить», зона для сообщения о результате. Валидация по списку валидных кодов.

### Список валидных кодов (пока захардкожен в `src/data/promo.js`)

- `SALE15` — 15% скидки;
- `SALE20` — 20% скидки;
- `WELCOME10` — 10% скидки.

### Acceptance criteria

1. Ввод `SALE15` + «Применить» → под инпутом появляется сообщение «Промокод применён: −15%» (зелёное).
2. Ввод `FAKECODE` + «Применить» → сообщение «Промокод недействителен» (красное).
3. Ввод пустой строки → кнопка disabled.
4. Регистр не важен: `sale15` = `SALE15`.
5. После успешного применения инпут переходит в состояние «применён», кнопка меняется на «Отменить».
6. Клик по «Отменить» сбрасывает промокод, инпут снова пустой.

### Test plan

- Юнит-тест `validatePromo(code)`: валидный код, невалидный код, пустая строка, смешанный регистр.

## Шаг 2. Пересчёт итога

### Scope

Применение процентной скидки к `subtotal` корзины. Отображение в блоке итогов: «Сумма: X», «Скидка по промокоду: −Y», «Итого: Z».

### Acceptance criteria

1. Без промокода: итог = сумма товаров.
2. С промокодом `SALE15` и товарами на 1000 ₽: скидка 150 ₽, итог 850 ₽.
3. Скидка округляется до целого рубля по правилам `Math.round`.
4. После отмены промокода (шаг 1, п. 6) итог возвращается к исходному значению.
5. В блоке итогов строка «Скидка» появляется только когда промокод применён.

### Test plan

- Юнит-тест `applyDiscount(subtotal, discountPercent)`: без скидки, с разными процентами, округление, с нулевым subtotal.

---

## Шаг 3. Сохранение в localStorage

### Scope

Применённый промокод сохраняется в `localStorage` и восстанавливается при следующем открытии корзины.

### Acceptance criteria

1. Применение `SALE15` → в `localStorage` под ключом `appliedPromo` лежит `{"code":"SALE15","discount":15}`.
2. Обновление страницы → промокод снова применён, итог пересчитан.
3. Отмена промокода → ключ удаляется.
4. Если в `localStorage` лежит невалидный код (изменился список, подставили руками) → при загрузке код игнорируется, ключ очищается.
5. Очистка корзины → промокод тоже сбрасывается.

### Test plan

- Юнит-тест чтения/записи в мок `localStorage`.
- Ручная проверка: применить, обновить, отменить, почистить корзину.

## Критерии рефакторинга (шаг 4 задания)

После реализации функция расчёта итога разбита на:

- `getSubtotal(items)` — сумма товаров до скидки;
- `applyDiscount(subtotal, discountPercent)` — сумма после применения процента;
- `calculateTotal(items, promoDiscount)` — композиция, используется в компоненте.

Каждая функция — чистая, без побочных эффектов, покрыта юнит-тестами. Поведение снаружи — без изменений.

## Decision log

- [x] Валидация промокода — синхронная функция, не хук. Причина: простая логика, тестируется легче.
- [x] Сообщение о результате — отдельный компонент `<PromoMessage status="success|error">`, а не условный JSX в корзине. Причина: переиспользуемость и читаемость.
- [x] Ключ `localStorage` — `appliedPromo`, плоский camelCase, как и остальные ключи проекта. Хранит JSON `{ code, discount }`, а не строку: процент нужен при загрузке, чтобы пересчитать итог без повторной валидации.
