# Release Notes 0.1.0

Учебный релиз магазина: каталог с фильтрами, корзина с промокодом, интеграция с API поставщика, MCP-инструменты для агента, тесты и подготовка релиза.

## Что нового

Каталог подключён к API поставщика. Приложение загружает товары по сети и переживает сбои: при ошибке сервера показывает кешированные данные, при полной недоступности — сообщение с кнопкой повторной загрузки. В редакторе подключён Playwright MCP — агент сам запускает e2e-тесты после изменений.

## Улучшения

- Скелетон загрузки вместо пустого экрана при ожидании данных.
- Четыре состояния каталога: `loading`, `retrying`, `fallback`, `failed`.
- Документация проекта: расширенный README, архитектурные решения, JSDoc для API-функций.

## Исправления

- Расчёт стоимости доставки учитывает скидку по промокоду.
- Адаптер каталога валидирует обязательные поля товара.

## Известные ограничения

- Кеш данных в localStorage ограничен ~5 МБ.
- Мок-API возвращает статические данные.
- Изображения товаров — плейсхолдеры.

## Итоговая функция

Поверх этого состояния реализуется выбранная итоговая функция. Финальный релиз добавит запись с новой функцией в этот файл.
