# Журнал рисков MCP

## Подключённые серверы

### Playwright MCP

- Пакет: `@playwright/mcp@latest`
- Транспорт: stdio через `npx`
- Назначение: автоматический запуск e2e-тестов агентом из редактора
- Политика подтверждений: только чтение — автоматически, меняющие состояние — подтверждение, `browser_evaluate`/`browser_run_code` — подтверждение обязательно
- Дата подключения: 2026-04-13

## Риски

| # | Риск | Вероятность | Последствия | Мера |
|---|---|---|---|---|
| R1 | Агент запускает `browser_run_code` с произвольным JS | низкая | критичное | Подтверждение обязательно |
| R2 | Агент кликает кнопки отправки на реальных страницах | средняя | серьёзное | Сквозные тесты только против локального сервера разработки. Подтверждение на меняющие состояние действия |
| R3 | Скачивание браузерного ядра Chromium при первом запуске зависает | средняя | мелкое | Документация предупреждает: первый вызов = ~3 минуты |
| R4 | Сквозные тесты нестабильны | средняя | мелкое | Использовать `browser_wait_for` вместо фиксированных таймаутов |
| R5 | MCP передаёт скриншоты с приватными данными | низкая | мелкое (только локальный dev) | Тестируем только мок-данные |

## Что не подключено и почему

- **GitHub MCP** — Cursor требует PAT (OAuth недоступен). Для работы с GitHub — `gh` CLI.
