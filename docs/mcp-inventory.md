# Каталог MCP

## Playwright MCP

- **Пакет:** `@playwright/mcp@latest` (Microsoft, Apache 2.0)
- **Транспорт:** stdio через `npx -y @playwright/mcp@latest`
- **Конфиг:** `.cursor/mcp.json` в корне проекта
- **Назначение:** агент сам запускает e2e-сценарии в браузере.
- **Политика подтверждений:** только чтение — автоматически, меняющие состояние — подтверждение, разрушительные (`browser_evaluate`, `browser_run_code`) — подтверждение обязательно

### Каталог инструментов

| Инструмент | Тип | Подтверждение |
|---|---|---|
| `browser_snapshot` | только чтение | автоматически |
| `browser_take_screenshot` | только чтение | автоматически |
| `browser_wait_for` | только чтение | автоматически |
| `browser_console_messages` | только чтение | автоматически |
| `browser_navigate` | меняющие состояние | подтверждение |
| `browser_click` | меняющие состояние | подтверждение |
| `browser_type`, `browser_fill_form` | меняющие состояние | подтверждение |
| `browser_evaluate` | разрушительные | подтверждение обязательно |
| `browser_run_code` | разрушительные | подтверждение обязательно |

## Что не подключено и почему

- **GitHub MCP** — требует PAT в Cursor. Для CI используем `gh` CLI напрямую.
- **Filesystem MCP** — Cursor имеет доступ к файлам проекта; дублирует встроенный функционал.
